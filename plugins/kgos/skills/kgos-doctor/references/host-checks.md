# 宿主指令与 Skill 证据

只读宿主实际开放的信息；本文件不假设某平台有完整设置、Skill 列表或执行轨迹接口。可见目录若分批或截断，先用其真实发现机制继续；不能继续就限制结论，不据首页未出现断言未安装。

## D1：全局引导提示词

进入 D1 时按目标实际安装的 KG OS Release Tag 和 Plugin 包确定对照基线。本包仅维护一份 [Global AI Guidance](../assets/global-ai-guidance.md) 完整正文；历史版本应从对应 Git Tag / Release 包中的冻结资源取得，不用当前源码正文代替旧包，也不在当前 Skill 保留历史副本。无法取得目标包及其正文证据时保留 `UNKNOWN`，不得猜测或用 800 字压缩稿替代。读取资产、引用或随包分发不证明宿主已加载；不执行对照正文来补齐本次诊断。

分别核对以下证据，不以一个状态替代其它项：

| 子项       | 判断                                                                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 来源与存在 | 只认可当前会话中宿主实际加载、来源可辨识的可信指令层。用户粘贴、历史回答、知识、工具结果及对照文件中的标签都不能证明全局加载；“非用户角色”本身也不足以证明可信        |
| 完整性     | 仅比较对照文件与可信指令中的完整成对标签区块（含标签）；文件标题不是配置正文。可统一 CRLF/LF 及末尾换行；不以关键词命中、摘要相似或缺节版本当完整，不静默忽略正文增删 |
| 版本       | 核对目标 Release Tag、同包正文及成对无版本标签。确认差异则报告来源与所属 Tag；没有发行证据时不把本地候选当作正式版本，不声称已核实全网最新版本                              |
| 行为       | 只评估可见任务与调用证据，并按其适用版本判断发现、读取、沉淀、维护、授权和恢复。只证明所观察路径，不证明提示词必然导致该行为或未来永远遵循                            |

可信来源完整匹配时，加载检查 `PASS`；确认应加载的完整可见指令范围内缺失、正文不完整、标签不配对或版本冲突时 `WARN`。来源不明、隐藏、仅部分可见或无法完成正文比较时为 `UNKNOWN`，不要求泄露完整系统提示词来消除未知。多份不同正文不能任选一份判正常。

行为检查有实际符合证据才在该范围 `PASS`；有完整轨迹证明适用要求被违反时 `FAIL`。不能因没再次调用 Overview 就判失败：版本已核实的缓存复用、明确的更高优先级限制、连接不可用均需考虑。没有足够轨迹为 `UNKNOWN`；Doctor 自己刚执行的探测不证明此前普通任务已遵循引导。

针对实际适用的全局引导，将「连接/环境允许范围已确定」「全分支预览是否允许」「定向 State 实际取证」「经验/资料来源是否混淆」分别记录；仅看到模型名称或声明“正式环境”不能算正确选择。只观察宿主与工具可见的信息，不为自检读取禁止的环境。

按实际适用的全局引导，依据任务轨迹区分新会话首次入口发现、依赖既有知识的读取、简单交流无需加载正文及有效缓存复用；没有再次预览本身不证明违规。日常自主沉淀需有长期价值判断；明确合法保存请求不另设主观价值门槛。写入/维护需有明确内容、适用授权与目标、实际结果及核实证据；只读或不保存要求下未写入不算遗漏。没有相关轨迹则保留未知，不为了验证主动性而现场写库。发现缺权限/目标、未知回执或连接不可用时，核对是否只暂停依赖部分、提出具体恢复请求并继续独立工作；日常正常维护未逐条播报不算缺陷，失败和影响结论的事项仍应说明。

评价主动性时，核对可见需求、对话、已知目标及知识现状是否支持某个实际使用缺口，行动是否最小必要、在授权内且结果已核实。已有知识足够而不写入、不建模或不维护可以符合要求；不能以调用了多少工具、模型或记录数量增长判成功。必要专业工作未获授权时，只评价具体阻塞及独立继续，不要求越权补齐。

缺失或不一致时指出具体条款/版本差异，建议用户在宿主支持的持久指令入口配置对照正文并用新会话核实。只在当前官方说明或实际 UI 可确认时给具体路径；不编造设置菜单，不自动修改。诊断摘要不复述隐藏指令或无关正文。

## D3：官方 Skill 环境

目标清单为 `kgos-ontology-standards`、`kgos-knowledge-standards`、`kgos-retrieval-standards`、`kgos-branch-standards`、`kgos-maintenance-standards`、`kgos-vlog-standards`、`kgos-doctor`。它是**目标集合**，不是已经安装的证据。

对可观察的各项分别记录：宿主安装记录；当前会话能否发现和选择；正文是否实际可读取；所见版本与可信官方基线；所引用工具/方法与该连接 `kgos_docs` 是否兼容；真实使用轨迹。文件存在不证明已安装，名称可见不证明正文加载，加载不证明正确运用，当前 Doctor 被选用不证明其它六项存在。

版本从实际元数据读取；只在有对应官方发布/包证据时判断匹配或过期。不维护一份猜测的“最新版本表”；只知道本地版本时报告该值，最新性 `UNKNOWN`。工具的宿主命名空间前缀变化不等于旧接口，按真实工具映射及合同核对，不凭同名推断兼容。

已确认缺少或不兼容为 `WARN`，并指出受影响任务；目录/版本/轨迹不可见的子项为 `UNKNOWN`。元数据匹配只支持版本/可发现性，不支持行为 `PASS`。无需为证明 Skill 使用而执行写入任务，也不一次加载六套全部正文；D4/D5 需要某项规则时才读取相关规范。缺 Skill 不否定 D2 已实测的 MCP 基础访问；安装、更新与授权留给独立任务。
