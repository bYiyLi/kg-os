## 4. 用户确认

**是否按照上述方案实施？**

仅在具体方案尚未确认时向用户提出这一问题；用户已直接指定并授权完整方案或已批准同一方案时，在批准范围内实施，不重复请示。未获具体方案确认时，不执行模型结构变更、Branch 创建或对应数据迁移；只读设计和“无结构改动”的复用建议不需要实施确认。
