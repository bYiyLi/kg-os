## Dependencies

- The examples import <https://purl.org/nemo/gufo#> while the ontology identifier is <http://purl.org/nemo/gufo#>; use the explicit local alias mapping to upstream/gufo/gufo.ttl, as documented by upstream for HTTPS retrieval.
- examples/common/gufoshapes.ttl and all seven example ontologies/tutorials are local.
- W3C time/RDF/OWL/XSD identifiers are vocabulary references; external validators listed in examples/tests/requirements.txt are not runtime dependencies of this reference package.

## Uncovered or distinct material

- gUFO implements a subset of UFO-A and minimal UFO-B; it is not complete UFO.
- Videos and separately licensed linked papers/books are not copied.
