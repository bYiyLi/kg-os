# 问题所需证据与模型驱动策略

本文件负责读取选择，不制定领域模型、写入规则或外部资料采集工程。根据当前任务识别目标和范围；已有足够依据时不强制再生成一份计划。

结合当前需求、对话及已知长期目标定位影响使用的证据缺口，区分尚未读取、可靠性不足、范围不适用和事实可能变化。已有有效知识足够支持当前结论时复用并结束检索，不为凑调用数量重复查询；发现需要纠错、建模或维护的有据缺口时，交给宿主按相应专业规则和实际授权继续，检索本身不授予写权限。

## 先看结论需要什么

| 问题意图 | 必需的证据边界 |
| --- | --- |
| 精确定位对象/属性 | 正确身份和上下文下的实际记录；已知准确 Ref 可直接读 |
| 询问“是否有” | 一个确属范围且条件成立的实例足以证明库中有；无匹配须另证覆盖 |
| 全部对象/计数 | 完整目标集合、正确判定条件及计数单位，不把排名候选当全集 |
| 几条经验/主题探索 | 相关且足够代表所给示例的材料；不声称发现全部或排名绝对最优 |
| 关系与影响分析 | 实际类型、方向、端点、关系属性及需要的直连/多跳范围 |
| 比较、解释原因或是否完成 | 支撑关键比较维度、因果或完成条件的证据，不只找相同关键词 |

用户已给出的知识库、Branch、时间、项目和要求保留；可从已授权上下文确定时不重复提问。若“当前”“全部”“相关”存在会改变结论的歧义且来源不能裁决，明确采用的有限解释或询问关键差异，不能悄悄换成容易查的子集。

先依据任务及可信连接配置限定实例、环境和用途；正式任务不默认读测试资料，失败不换库。新会话首次使用获准 KG OS 时查看入口及用途；同实例混用不同用途知识须先限范围，不越界读取后过滤。无法安全枚举时定向读已知目标，仍不明才澄清。问候等简单交流无需加载正文，不为无关问题扩展检索。

同名不同实体、同一实体不同版本、同一事实不同适用范围先分清；身份依实际模型和证据，不由相关性评分决定。多库任务仅涉及实际可见且允许访问的连接，不发明全账户知识库发现能力。

## 渐进理解真实结构

已知准确 Object Ref、语义与所属 State 时直接读取。需要字段或关系含义时读相关 Definition；未知模型才从 Ontology 概览发现。Domain 可辅助导航，但不是实例分区、权限或命名空间；还需检查相关未归类定义和跨 Domain 关系，不能由一页目录断言别处没有知识。

用实际 Label/Type、Property 及真实索引名编写查询；示例 Document/Person 等不是预置模型。Definition 的 `items=[]` 不代表没有属性或实例，需看该项详情；描述缺失不授权 AI 编造业务含义。一次读取已有足够上下文时，不重新全库扫描模型。

## 选择最能解决当前缺口的方法

精确身份、状态、日期或数量优先使用能表达该条件的结构化查询；已知 Ref 不必再搜索。具体术语可从全文入手；表达不同、概念探索可从语义检索入手；依赖、归属和证据链用真实关系按需补全。组合可在单条 Cypher 或多次读取中完成，不强制采用一种编排方式。

检索候选与确认分开：已命中疑似决策后，下一步可能只需读取它的适用项目与验收依据，不必继续堆叠语义搜索。查询改写可补别名、术语或不同表达，但保留原问题的主体、否定、时间和条件；扩宽结果后再按原问题筛选，不把宽泛问题的结果拿来回答原来的限定问题。

索引覆盖依据实际 target、字段与 State 判断。Full-text 受当前索引分词/字段影响，不是逐字等于；Managed Semantic 单 STRING source 缺失/null 的对象不参与该索引。存在索引不等于它覆盖了所有相关资料，相关细节和参数始终核对当前 `kgos_docs`。向量分数不是身份验证或事实可信度；不同索引/方法的分数不能未经约定直接相加、取平均或转换为概率。

已有公共 Graph 支持的 Raw Vector 查询与 Managed Semantic 不同；可以在真实能力、已有数据和权限内选用，不能假装普通文本就是向量，也不能为回答问题自行建索引、生成并保存向量或移植另一接口的过滤保证。缺能力时选择满足原意图的只读替代，说明无法维持的覆盖/排名要求。

## 扩展图上下文而不扩大事实

按问题选择方向、类型和跳数。A依赖B、B依赖C支持路径存在，不自动等于A直接依赖C；合作/任职/支持等关系也没有普遍传递性。关系属性可能属于某次任职、某个项目范围，不从端点属性或其它关系继承。

路径可以重复到达同一对象；需要对象清单或数量时按实际身份去重，需要事件/边/路径时保留它们各自的身份。多个边的共同出现不自动证明时间重叠、因果或同一业务上下文。避免无限遍历；达到资源/范围限制就准确说明只覆盖哪些路径，不能隐藏截断。

投影保留当前判断必要的身份、限定条件、证据定位和关系属性，减少无关正文；不能为省上下文删掉决定结论的内容。摘要或命中片段不足以判断否定、时间或状态时，再读取相关完整内容，已充分则不无条件回读一切。
